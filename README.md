# EventForce Management System

Salesforce-based CRM for managing events, clients, vendors, venues and feedback.

## Key Features

- Event, Client, Vendor, Venue & Feedback management
- Automated client reminders
- Event cancellation approval
- Venue & booking management
- Reports and Dashboards

## Reports & Dashboard

- Upcoming Events by Month
- EventForce Operations Dashboard
